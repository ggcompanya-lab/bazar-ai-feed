# Bazar AI Feed

Публичен продуктов източник само за **Bazar.bg**. Управлява се през одобрени продуктови записи от ChatGPT и свързан GitHub.

## Статус
Първоначална инфраструктура. **Няма публикувани продукти и няма активен feed.xml.** Файлът се генерира едва когато има валидна, изрично одобрена обява.

## Работен процес
1. Собственикът предоставя реални снимки и информация за произволен продукт.
2. AI предлага категория, цена, заглавие, описание и снимки за преглед.
3. Изричното **„Качвай“** одобрява точно показаната обява.
4. Одобреният продуктов запис влиза в products.json; генерираният feed.xml се записва в хранилището.
5. Bazar.bg изтегля публичния feed от GitHub Pages в интервала на активния Premium план.

## Първа настройка
1. В GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
2. Потвърдете, че GitHub Pages действително е активиран и публичният адрес се отваря.
3. Валидирайте полетата за съответната Bazar категория. Примерният файл за категория 311 **не е универсален за всички категории**.
4. При първата одобрена обява: качете реалните продуктови снимки на публични HTTPS адреси; създайте feed.xml и проверете XML съдържанието.
5. Едва тогава добавете feed URL в Bazar.bg → Автоматичен feed и съпоставете категориите.

## Безопасност
- Не записвайте пароли, API ключове, лични чатове или непубликувани лични данни в това **публично** хранилище.
- Не публикувайте тестови/измислени обяви.
- Използвайте снимки, които вярно представят състоянието на артикула.
- Не променяйте стабилния external_id при обновяване на артикул.
- При грешки и непълни полета процесът спира, вместо да публикува невалидна обява.
- Не замествайте неочаквано цял активен продуктов каталог с празен XML: това може да архивира обяви.

**Важно:** GitHub Pages е статичен хостинг. Той не предоставя автоматичен достъп до чат съобщенията на Bazar.bg или директно управление на поръчките.
