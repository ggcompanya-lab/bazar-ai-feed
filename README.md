# Bazar AI Feed — автоматизирани обяви

Само за **Bazar.bg**. Официалният пример `bazar-import-311.xml` е използван за полетата на първия продукт. Различните категории имат различни допълнителни атрибути.

## Един път: активиране

1. **GitHub → Settings → Pages → Source: GitHub Actions**. Предишната настройка *Deploy from a branch* не е подходяща за автоматично генерирани файлове: GitHub Actions commit с `GITHUB_TOKEN` не стартира Pages build. Новият workflow генерира, тества и публикува Pages артефакта директно.
2. Провери успешен workflow **Build and deploy Bazar AI Feed** в GitHub → Actions.
3. Провери живия XML: https://ggcompanya-lab.github.io/bazar-ai-feed/feed.xml
4. Отвори **Bazar.bg → Профил → Импорт → Автоматичен feed → Нов feed** и постави постоянния URL от т.3. Анализирай, съпостави категориите и активирай импорта **веднъж**. Нужно е активирано Premium обслужване. Ако платформата поиска корекция на полета — направи я веднъж и обнови `category_registry.json`.
5. Провери обявата в Bazar.bg. Само видима обява или изрично потвърждение от платформата означава статус *публикувана*.

## Всеки следващ продукт

1. Изпращаш снимки и данни в ChatGPT. AI подготвя обява, цена и категория; ползва наличния `category_registry.json`.
2. Преглеждаш. Командата **„Качвай“** е разрешение само за конкретната обява.
3. AI записва реалните снимки на устойчив публичен HTTPS адрес; обновява `products.json` със статус `approved_pending_import` и `seller_approved: true`.
4. **GitHub Actions автоматично** тества, генерира и публикува XML и снимките. За нов продукт не се настройва нов feed URL.
5. Bazar.bg го импортира при следващата периодична синхронизация. AI проверява резултата, когато има достъп до съответния акаунт.

**Важно:** ChatGPT няма постоянен фонов достъп до Bazar.bg от обикновен чат. За преглед на съобщенията, статуса на обявите и еднократната настройка на потребителския интерфейс използвай ChatGPT Work с оторизиран браузър. GitHub Actions автоматизира инфраструктурата, но не гарантира приемане на обява от Bazar.

## Контрол на инвентара

- `draft` — не се експортира.
- `approved_pending_import` — има изрично одобрение; чака синхронизация/проверка.
- `approved` или `live` — остава във feed; `live` се задава само след проверка в Bazar.
- `sold`, `paused` — не се експортират при следващото успешно обновяване.
- `external_id` е постоянен и се използва за обновяване без дубликати.
- Ако всички артикули се премахнат, генераторът спира, освен при изрично `allow_empty_feed: true` за планирано сваляне на всички обяви. Празен каталог може да прекрати обявите в Bazar — не използвай без потвърждение.

## Технически файлове

- `products.json` — одобрени и чернови с публично предназначена информация
- `category_registry.json` — веднъж проверени кодове и категории
- `build_feed.py` — XML генератор
- `preflight.py`, `test_feed.py`, `verify_feed.py` — проверки
- `.github/workflows/build-feed.yml` — GitHub Actions → GitHub Pages

Никакви пароли, токени, лични чатове и частни бележки в публичния GitHub проект.
